# SCORING METHODOLOGY

For repeatability across waves, the scoring formula is:

```
priority_score = (authority_weight x relevance_weight x achievability_weight) / time_to_link_weeks

authority_weight:  A=4, B=3, C=2, D=1
relevance_weight:  4 (perfect topical match), 3 (strong), 2 (moderate), 1 (weak)
achievability_weight:  Easy=3, Medium=2, Hard=1
time_to_link_weeks:  estimated weeks from send to live link, conservative
```

Worked example - Hypepotamus (rank 1):
- authority 2 (DR 45 = C tier)
- relevance 4 (Macon founder profile is perfect-fit)
- achievability 3 (single editor email, no editorial committee)
- time_to_link 3 weeks
- score = (2 x 4 x 3) / 3 = **8.0**

Worked example - Wired (not in top 50):
- authority 4 (DR 95 = A)
- relevance 3 (security beat fit)
- achievability 1 (Hard - need signed client permission, top-of-funnel byline)
- time_to_link 16 weeks
- score = (4 x 3 x 1) / 16 = **0.75**

Hypepotamus scores 10x higher despite Wired's higher DR because of much better achievability and turnaround. This is why "rank by DR alone" produces worse outreach plans than "rank by composite priority."
