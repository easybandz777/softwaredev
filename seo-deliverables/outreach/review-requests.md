# Cadence Summary

## Default outreach cadence per client (5 contact-touches max)

- **Day 0:** Initial ask via preferred channel (email or personal text - see tier guidance)
- **Day 3:** SMS follow-up (only if preferred channel was email or personal text and no response)
- **Day 7:** Email follow-up (the lighter touch from review playbook section 3)
- **Day 14:** Final personal text from Bill (if relationship supports it; skip otherwise)
- **After Day 14:** Stop. Mark as "declined" in tracker if no response.

## Stop conditions

- Client replies (any sentiment): stop and log
- Client requests no further contact: stop, 12-month cooldown
- Negative-review surfaces: trigger negative-recovery flow, NOT additional asks
- Project still ongoing or unresolved: do not ask until milestone

## Volume cap

- Maximum 5 review requests sent in any one calendar week
- Space asks 2-3 days apart minimum to avoid clustering

## Tracking

Every send and every response goes into 00-MASTER-TRACKER.md with:
- Client name
- Project name (slug)
- Tier (1 / 2 / 3)
- Send date
- Channel used
- Response (yes / no / pending / declined)
- Review URL (if landed)
- Review star count
- Negative-review flag (true if 1-2 star)
- Resolution date
- Update-ask date (if applicable)
